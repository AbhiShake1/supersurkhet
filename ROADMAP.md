# SuperSurkhet Roadmap

This roadmap outlines our development priorities for SuperSurkhet, with focus on features critical for our first softlaunch in Surkhet, Nepal.

## HIGH PRIORITY (Must have for shippable app)

- [ ] [HIGH] Implement offline-first architecture for PWA and Expo app with proper data caching and sync
- [ ] [HIGH] Build anonymous user ID generation system with frictionless authentication flow
- [ ] [HIGH] Develop Fonepay payment integration with business-specific API key configuration
- [ ] [HIGH] Build data import/export functionality for business migration
- [ ] [HIGH] Create unified business discovery routes (/restaurants, /retail, etc.) showing all businesses of type
- [ ] [HIGH] Enhance retail client view and unified discovery experience
- [ ] [HIGH] Refine restaurant module (menu management, order tracking)
- [ ] [HIGH] Implement business logo upload and display across client pages
- [ ] [HIGH] Build robust hierarchical permission system with granular access control
- [ ] [HIGH] Enhanced QR scanner supporting our format, WiFi QR codes, and product barcodes

## MEDIUM PRIORITY (Nice to have for softlaunch)

- [ ] [MEDIUM] Create business QR code generation system with QR tab in business settings
- [ ] [MEDIUM] Implement color palette extraction from business logos for custom theming
- [ ] [MEDIUM] Implement webhook system for real-time event notifications
- [ ] [MEDIUM] Develop public API infrastructure for external integrations

## LOW PRIORITY (Can delay post softlaunch)

- [ ] [LOW] Create visual onboarding flow for new business owners
- [ ] [LOW] Implement progressive disclosure for simplified user experience
